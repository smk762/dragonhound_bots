# Telegram Auto Emoji

This project listens to messages from specific telegram channels, and reacts to keywords with relevant emojis (if sent from whitelisted users).

## Features

- **Keyword-based Emoji Reactions**: Reacts with specific emojis based on message content keywords
- **Channel and User Whitelisting**: Restrict reactions to specific channels and users
- **Containerized Deployment**: Dockerized for easy deployment and scalability
- **Environment-based Configuration** using `.env` file for sensitive data
- **Dependency Management with Poetry**: Ensures reproducible environments across development, testing, and production

## Project Structure

emoji_react/ 
├── app/
│ ├── main.py            # FastAPI app and Telegram bot logic

└── .env # Environment variables for sensitive data


## Getting Started

### Prerequisites

- **Docker**: [Install Docker](https://docs.docker.com/get-docker/) for containerization
- **Poetry**: [Install Poetry](https://python-poetry.org/docs/#installation) for dependency management
- **Telegram API Id/Hash**: See [https://core.telegram.org/api/obtaining_api_id](https://core.telegram.org/api/obtaining_api_id) for details

### Installation

**Clone the repository**:

   ```bash
   git clone https://github.com/smk762/dragonhound_bots -b emoji
   cd dragonhound_bots/telegram/emoji_react
   ```

**Set Up Environment Variables**:

Create a .env file in the project root directory and fill it with your bot token, whitelisted channels, and users.

    ```bash
    BOT_TOKEN=your_bot_token_here            # Currently unused.
    CHANNEL_WHITELIST=1234567890,9876543210  # Comma-separated list of channel IDs. Remove the `-100` prefix.
    USER_WHITELIST=123456789,987654321       # Comma-separated list of user IDs.
    API_ID=your_api_id                       # See https://core.telegram.org/api/obtaining_api_id
    API_HASH=your_api_hash                   # See https://core.telegram.org/api/obtaining_api_id
    SESSION=smk                              # After first run and authenication outside dicker, the session will store your credentials.
    ```

    To find the channel and user ids, use the telegram web app. They will be present in the url of the user or channel you select.

**Install Dependencies**:

Use Poetry to install project dependencies:

    ```bash
    poetry install
    ```

**Authenticate**:

Run outside docker to generate your [session file](https://docs.telethon.dev/en/stable/concepts/sessions.html)

    ```bash
    python3 main.py
    ```
It will ask for your mobile number and send a passcode to authenticate. Once done, Ctl-C to exit.

**Build and Run the Docker Container**:

```bash
docker compose up --build
```

## Configuration

Customize the keywords and associated emojis by modifying `app/emoji_keywords.py`:

```python
EMOJI_KEYWORDS = {
    'happy': ["😊", "😁", "😃", "🙂", "😄"],
    'sad': ["😢", "😞", "😭", "😩", "😔"],
    'love': ["❤️", "😍", "💖", "💕", "💘"],
    'angry': ["😠", "😡", "🤬", "😤", "😾"],
    'surprised': ["😮", "😯", "😲", "😳", "😱"]
}
```
Note: Not all emojis are supported. Check logs while testing keywords to confirm.
