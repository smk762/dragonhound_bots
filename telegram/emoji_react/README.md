# Telegram Bot with FastAPI, Docker, and Poetry

This project is a Telegram bot built using FastAPI, containerized with Docker, and managed with Poetry for dependency management. The bot listens to messages from specific channels, reacts to keywords with relevant emojis, and is designed for easy deployment in containerized environments.

## Features

- **Webhook-based** Telegram bot using FastAPI
- **Keyword-based Emoji Reactions**: Reacts with specific emojis based on message content keywords
- **Channel and User Whitelisting**: Restrict reactions to specific channels and users
- **Containerized Deployment**: Dockerized for easy deployment and scalability
- **Environment-based Configuration** using `.env` file for sensitive data
- **Dependency Management with Poetry**: Ensures reproducible environments across development, testing, and production

## Getting Started

### Prerequisites

- **Docker**: [Install Docker](https://docs.docker.com/get-docker/) for containerization
- **Poetry**: [Install Poetry](https://python-poetry.org/docs/#installation) for dependency management
- **Telegram Bot Token**: Obtain a bot token by creating a bot via [BotFather](https://core.telegram.org/bots#botfather) on Telegram

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/smk762/dragonhound_bots
   cd dragonhound_bots/telegram/emoji_react
   ```

2. **Set Up Environment Variables**:

Create a .env file in the project root directory and fill it with your bot token, whitelisted channels, and users.

    ```bash
    BOT_TOKEN=your_bot_token_here
    CHANNEL_WHITELIST=-1001234567890,-1009876543210  # Comma-separated list of channel IDs
    USER_WHITELIST=123456789,987654321               # Comma-separated list of user IDs
    ```

3. **Install Dependencies**:

Use Poetry to install project dependencies:

    ```bash
    poetry install
    ```

## Running the Bot
Using Docker and Docker Compose

1. **Build and Run the Docker Container**:

    ```bash
    docker compose up --build
    ```
2. **Set Up Telegram Webhook**:

Once the container is running, expose it to the internet using a tool like ngrok or deploy it on a server with HTTPS. Update your Telegram bot’s webhook URL to point to your server:

    ```bash
    curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook" -d "url=https://your-domain.com/emoji_webhook"
    ```

Replace https://your-domain.com/emoji_webhook with your server’s public HTTPS URL.

## Running Locally for Development

- Activate the Poetry Virtual Environment:
```bash
poetry shell

```

- Run the FastAPI Server:
```bash
uvicorn app.main:app --reload
```

This will start the server on http://127.0.0.1:9524.

- Expose Local Server for Webhook Testing: Use ngrok to expose your local server to the internet for Telegram to send updates:

```bash
ngrok http 9524
```

Set the webhook to the ngrok HTTPS URL as described above.

## Configuration

- Customize the keywords and associated emojis by modifying `app/emoji_keywords.py`:

```python
EMOJI_KEYWORDS = {
    'happy': ["😊", "😁", "😃", "🙂", "😄"],
    'sad': ["😢", "😞", "😭", "😩", "😔"],
    'love': ["❤️", "😍", "💖", "💕", "💘"],
    'angry': ["😠", "😡", "🤬", "😤", "😾"],
    'surprised': ["😮", "😯", "😲", "😳", "😱"]
}
```

- Configure sensitive and environment-specific settings in the .env file. Here’s a summary of key variables:
```bash
BOT_TOKEN: Your Telegram bot token from BotFather.
CHANNEL_WHITELIST: Comma-separated list of channel IDs where the bot will react to messages.
USER_WHITELIST: Comma-separated list of user IDs that are allowed to trigger reactions.
```

Running Tests
If you’ve added tests, you can run them with Poetry:

```bash
poetry run pytest
```
## Deployment
To deploy in production, follow these steps:

- Use `docker-compose.yml` to deploy the container on your server.
- Ensure the webhook URL is correctly set to the HTTPS endpoint of your server.
